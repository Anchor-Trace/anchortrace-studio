# Contributing

Bug reports with the record, the evidence and what the page showed are the most useful contribution.

## Setup
Node >= 22, pnpm 11. `pnpm install --frozen-lockfile`, `pnpm run typecheck`, `pnpm test`, `pnpm build`. For browser tests: `pnpm exec playwright install chromium` (or `PW_CHANNEL=chrome` with Google Chrome installed), then `pnpm test:e2e`.

## Rules that keep the studio honest
- No reconciliation logic here. Verdicts, findings and numbers come from the SDK's report; if the verdict is wrong, fix the SDK.
- Every displayed state comes from executed SDK output. Do not hard-code example results; examples are generated by the SDK.
- Never weaken the privacy posture: no network access (keep `connect-src 'none'`), no storage, no analytics, no remote fonts or scripts.
- Keep the not-a-bank-payout statement visible and keep synthetic data labelled synthetic.
- Colour is never the only signal; every control is keyboard operable; add an e2e assertion with any new interaction, and keep the axe scans clean.
- Updating the SDK means re-pairing (see `SPEC.md` section 4): new tarball in `vendor/`, schemas copied, `pairing.json` updated, tests green.
- Commits: one logical unit each, conventional prefixes, no AI co-author trailers.
